  ## 🚀 What is MarySum?

  MarySum is an AI-powered desktop application that
  automatically:
  - 🎙️ Records your meetings
  - 📝 Transcribes audio with Whisper AI
  - 👥 Identifies different speakers
  - 📊 Generates intelligent summaries
  - 💾 Exports to PDF/Text

  ## 💎 Features

  ### Free Tier
  - ✅ AI transcription with Whisper
  - ✅ Speaker diarization
  - ✅ Meeting summaries
  - ✅ Export to PDF/Text
  - ✅ Up to 60 minutes per recording
  - ✅ Up to 400MB file uploads

  ### Pro Tier
  - ✨ Everything in Free, plus:
  - 🗺️ Mind Map visualization
  - 🎯 Focus Mode for distraction-free work
  - ⏱️ Unlimited recording time
  - 📦 Unlimited file size
  - 🎯 Priority support

  ## 📋 System Requirements

  - **OS**: Windows 10 or 11 (64-bit)
  - **RAM**: 4GB minimum (8GB recommended)
  - **Storage**: 500MB free disk space
  - **Internet**: Optional (for AI features)
